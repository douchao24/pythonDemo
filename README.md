# FastAPI 后台项目标准化搭建手册

适用：后续所有 FastAPI 新项目一键复刻、按流程搭建，含搭建步骤 + 分层作用 + 技术原理 + 避坑指南，无冗余完整业务代码，只留流程和原理解释。

## 文档说明

1. 本手册基于实战落地项目整理，为通用标准化搭建流程。
2. 不提供完整业务代码，只讲搭建顺序、目录分层、技术应用原理、核心逻辑。
3. 后续新建任何后台服务，严格按本手册步骤即可快速搭建。
4. 适配：Python 3.8+ / FastAPI / SQLAlchemy / Pydantic v2 / JWT 登录鉴权。

---

## 一、核心技术栈及作用说明

| 技术 | 用途解释 |
|------|----------|
| FastAPI | 高性能异步 Web 接口框架，自动生成接口文档 |
| Uvicorn | ASGI 异步服务器，用于启动 FastAPI 项目 |
| SQLAlchemy 2.0 | ORM 数据库框架，用对象操作数据库，无需手写 SQL |
| Pydantic v2 | 请求参数自动校验、数据库模型与响应数据转换 |
| passlib | 用户密码加密存储，避免明文入库 |
| python-jose | 生成、解析 JWT 令牌，实现无状态登录鉴权 |
| pydantic-settings | 读取 .env 环境配置，统一管理全局变量 |
| SQLite | 轻量文件型数据库，无需安装服务，可无缝切换 MySQL |

## 二、第一步：项目环境初始化流程

### 1. 基础操作步骤

1. 新建空项目文件夹。
2. 创建 Python 虚拟环境（隔离项目依赖，避免版本冲突）。
3. 编写 `requirements.txt` 写入所需依赖。
4. 激活虚拟环境，批量安装依赖包。

### 2. 关键技术点解释

- **虚拟环境**：每个项目独立依赖，不污染全局 Python 环境。
- **环境配置抽离**：所有端口、密钥、数据库地址不放代码里，统一放 `.env`。
- **开发模式启动**：`--reload` 代码修改自动重启，无需手动重启服务。

## 三、第二步：标准固定目录结构 & 每层职责

```plaintext
项目根目录/
├── app/                        # 项目主程序根包
│   ├── main.py                 # 项目唯一入口、路由汇总、服务启动
│   ├── core/                   # 核心基础层（全局通用）
│   ├── models/                 # 数据库 ORM 模型层（定义数据表结构）
│   ├── schemas/                # 数据校验层（请求入参、响应出参规则）
│   ├── api/                    # 接口路由层（按模块、按版本拆分接口）
│   └── utils/                  # 通用工具层（加密、JWT、公共函数）
├── .env                        # 环境变量配置文件（敏感配置单独存放）
└── requirements.txt            # 项目依赖清单
